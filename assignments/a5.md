For this assignment I made a fan that turns on when you breathe on it. Breath is warm and full of water vapor, so the humidity reading on the DHT11 jumps when you breathe near it. The Arduino reads the humidity with the DHT library, and the more it goes up, the faster the fan spins. The fan is the kit's DC motor, switched by an IRLZ44N N-MOSFET from a separate 12 V wall adapter, and the Arduino controls the speed with `analogWrite()`.

**Why these parts.** I used a 330 Ω resistor between D9 and the gate because the gate acts like a small capacitor, and without a resistor it would pull a big burst of current from the pin every time it switches. With 330 Ω the most it can pull is 5 V / 330 Ω = 15 mA, which is under the Arduino's 20 mA per pin. The 10 kΩ resistor from gate to ground is a pull-down. When the Arduino resets or I upload code, D9 is just floating for a moment, and the pull-down holds the gate at 0 V so the motor doesn't randomly turn on. The 1N4007 diode is the flyback diode. The motor is a coil, so when the MOSFET switches off the current keeps trying to flow, and the diode gives it a path back around the motor instead of making a big voltage spike on the drain. The 100 µF and 0.1 µF capacitors go between 12 V and ground. The big one helps with the motor's surge when it starts, and the small ceramic one handles the fast noise from the motor's brushes.

**Voltages and currents.**

The gate. When D9 is HIGH, R1 and R2 make a voltage divider, so the gate gets 5 V × 10k / (10k + 330) = 4.84 V. The IRLZ44N turns on between 1 and 2 V and is fully on at 5 V, so 4.84 V is enough. The current through R2 while D9 is HIGH is 5 V / 10.33 kΩ = 0.48 mA.

The motor. The kit motor is rated for 3 to 6 V, but my supply is 12 V, so I can't run it at 100%. PWM on D9 switches the motor on and off about 490 times a second, so the motor gets 12 V × duty on average. I capped the duty at 106 out of 255, which is 42%, so the most the motor gets is about 12 × 0.42 = 5 V on average. The slowest speed is 38 out of 255, about 1.8 V. I estimated the motor draws about 0.25 A while running.

The drain. When the MOSFET is on, the drain is almost at 0 V, about 0.25 A × 0.025 Ω = 6 mV, because the MOSFET's on-resistance is tiny. When it's off, the drain goes up to 12 V, and for a moment at turn-off it goes to about 12.9 V because the diode drops around 0.9 V.

**How much current the MOSFET can handle.** The IRLZ44N's datasheet says the max continuous drain current is 47 A, but that's with a heatsink, and I don't have one. Without a heatsink, the datasheet's 62 °C/W rating means it can only get rid of about (175 − 25) / 62 = 2.4 W, which works out to around 9.8 A at 0.025 Ω. My motor only uses about 0.25 A, so the MOSFET heats up by 0.25² × 0.025 = 1.6 mW, which is basically nothing. Even if the motor stalled and pulled 1 A, that would only be 25 mW.

## Code

The code first records the room's humidity for 10 seconds while the fan is off. After that, every 2 seconds it reads the humidity again, and if it's at least 3 points higher than the room, the fan turns on. The speed goes up the more the humidity goes up, until 25 points above the room, where the fan is at its max.

When `pinMode(FAN_PIN, OUTPUT)` runs, D9 changes from an input (floating, with only the 10 kΩ resistor holding the gate at 0 V) to an output. It starts LOW, so the motor stays off. `dht.begin()` sets D2 as an input with the internal pull-up turned on, so the data line sits HIGH when the sensor isn't sending anything.

```cpp
// Adafruit "DHT sensor library": handles the DHT11's single-wire timing and returns humidity
#include <DHT.h>

// D2 reads the DHT11 module's data pin (S)
const int DHT_PIN = 2;
// D9 is a PWM pin (490 Hz); it drives the MOSFET's gate through a 330 ohm resistor
const int FAN_PIN = 9;

// The fan starts once humidity is this many percentage points above the room baseline
const float START_RISE = 3.0;
// At this many points above the baseline the fan is at full speed
const float FULL_RISE = 25.0;
// The motor is rated 3-6 V but the supply is 12 V, so full speed is capped at 106/255 = 42% duty, about 5 V on average
const int MAX_DUTY = 106;
// Slowest PWM value (15% duty, about 1.8 V on average) that keeps the motor and blade turning; lower values stall it
const int MIN_DUTY = 38;
// A stopped motor needs more than MIN_DUTY to break free, so it gets a short kick at the 5 V maximum
const int KICK_DUTY = MAX_DUTY;
// Length of that kick in milliseconds
const unsigned long KICK_MS = 150;
// Read every 2 seconds, since the DHT11 and its library allow at most one reading per 2 s
const unsigned long READ_MS = 2000;
// Change the PWM value by 1 every 30 ms, so a full MIN_DUTY to MAX_DUTY change takes about 2 seconds
const unsigned long RAMP_MS = 30;
// Number of readings averaged at startup to record the room's humidity (5 readings x 2 s = 10 s)
const int BASELINE_READINGS = 5;

// Sensor object for a DHT11 on D2
DHT dht(DHT_PIN, DHT11);
// Room humidity in percent, recorded once at startup and then fixed; -1 means not yet known
float baseline = -1;
// The PWM value the fan is heading toward
int targetDuty = 0;
// The PWM value currently on D9
int currentDuty = 0;
// The time of the last sensor reading
unsigned long lastReadAt = 0;
// The time of the last one-step speed change
unsigned long lastRampAt = 0;

// Runs once at power-up or reset
void setup() {
  // Open the serial port at 9600 baud to log each reading
  Serial.begin(9600);
  // Until this line D9 is an INPUT (high impedance), so the 10 kohm pull-down holds the gate at 0 V and the motor is off
  // pinMode makes D9 an OUTPUT; its output latch is still 0 from reset, so it drives LOW (0 V) and the motor stays off
  pinMode(FAN_PIN, OUTPUT);
  // Write a duty of 0 anyway, so the fan is off even if this setup() is not following a full reset
  analogWrite(FAN_PIN, 0);
  // Start the sensor; the library sets D2 to INPUT_PULLUP, a high-impedance input with an internal pull-up to 5 V
  dht.begin();

  // Tell the Serial Monitor that calibration has started and to keep breath away from the sensor
  Serial.println("Recording baseline humidity, keep away from the sensor for 10 s");
  // Running total of the good readings
  float total = 0;
  // How many readings were good
  int good = 0;
  // Take BASELINE_READINGS readings with the fan held off
  for (int i = 0; i < BASELINE_READINGS; i++) {
    // Wait out the library's 2 s minimum between readings
    delay(READ_MS);
    // Read the room's humidity in percent
    float humidity = dht.readHumidity();
    // Only count readings the sensor actually answered
    if (!isnan(humidity)) {
      // Add this reading to the total
      total += humidity;
      // Count it
      good++;
    }
  }
  // Use the average as the fixed baseline, if at least one reading worked
  if (good > 0) {
    // Average of the good readings
    baseline = total / good;
  }
  // Label the recorded baseline in the log
  Serial.print("baseline=");
  // Print it to one decimal place (-1 means every reading failed, so the first good one in loop() is used)
  Serial.println(baseline, 1);
  // Start the reading timer now so the next reading is 2 s after calibration
  lastReadAt = millis();
}

// Runs over and over after setup()
void loop() {
  // Use one timestamp for every check in this pass through the loop
  unsigned long now = millis();

  // Take a new reading once every READ_MS
  if (now - lastReadAt >= READ_MS) {
    // Restart the reading timer
    lastReadAt = now;
    // Ask the DHT11 for relative humidity in percent
    float humidity = dht.readHumidity();

    // The library returns NaN when the sensor does not answer (usually a loose wire)
    if (isnan(humidity)) {
      // Report the failure and keep the fan where it is
      Serial.println("DHT11 read failed");
    } else {
      // If calibration failed, fall back to the first good reading as the baseline
      if (baseline < 0) {
        // Use this reading as the baseline
        baseline = humidity;
      }
      // How far above the room's humidity the air at the sensor is
      float rise = humidity - baseline;

      // A small rise is room drift, not a breath
      if (rise < START_RISE) {
        // Turn the fan off
        targetDuty = 0;
      } else {
        // Cap the rise at FULL_RISE, since the fan cannot go above full speed
        float capped = min(rise, FULL_RISE);
        // Scale START_RISE..FULL_RISE onto MIN_DUTY..MAX_DUTY, so more breath means more speed
        targetDuty = MIN_DUTY + (int)((capped - START_RISE) * (MAX_DUTY - MIN_DUTY) / (FULL_RISE - START_RISE));
      }

      // Label the humidity in the log
      Serial.print("humidity=");
      // Print the humidity in percent
      Serial.print(humidity, 0);
      // Label the baseline
      Serial.print(" baseline=");
      // Print the baseline to one decimal place
      Serial.print(baseline, 1);
      // Label the target PWM value
      Serial.print(" target=");
      // Print the PWM value the fan is heading toward
      Serial.println(targetDuty);
    }
  }

  // Change the speed by at most one step every RAMP_MS
  if (now - lastRampAt >= RAMP_MS) {
    // Restart the ramp timer
    lastRampAt = now;

    // The fan is slower than it should be
    if (currentDuty < targetDuty) {
      // A stopped motor needs a kick to start turning
      if (currentDuty == 0) {
        // Maximum allowed power for a moment to overcome the stopped motor's friction
        analogWrite(FAN_PIN, KICK_DUTY);
        // Hold the kick for KICK_MS
        delay(KICK_MS);
        // Drop to the slowest steady speed, then ramp up from there
        currentDuty = MIN_DUTY;
      } else {
        // Speed up by one step
        currentDuty++;
      }
      // Send the new duty to the MOSFET's gate
      analogWrite(FAN_PIN, currentDuty);
    } else if (currentDuty > targetDuty) {
      // Below MIN_DUTY the motor would stall, so from there go straight to off; otherwise slow by one step
      currentDuty = (currentDuty <= MIN_DUTY) ? 0 : currentDuty - 1;
      // Send the new duty to the MOSFET's gate
      analogWrite(FAN_PIN, currentDuty);
    }
  }
}
```

For each motor, one input HIGH and the other LOW makes it go forward, switching them makes it go backward, and both the same makes it stop.

```cpp
// left motor pins
ENA = 9, IN1 = 8, IN2 = 7
// right motor pins
ENB = 10, IN3 = 4, IN4 = 5

// set one motor's direction (+1 forward, -1 back, 0 stop) and speed (0-255)
function drive(en, inA, inB, dir, speed):
  // forward: A HIGH, B LOW
  if dir == +1: digitalWrite(inA, HIGH); digitalWrite(inB, LOW)
  // backward: A LOW, B HIGH
  if dir == -1: digitalWrite(inA, LOW); digitalWrite(inB, HIGH)
  // stop: both LOW
  if dir == 0: digitalWrite(inA, LOW); digitalWrite(inB, LOW)
  // PWM on the enable pin sets the speed
  analogWrite(en, speed)

setup:
  // all six pins are outputs and start LOW, so the motors start stopped
  pinMode(ENA, IN1, IN2, ENB, IN3, IN4, OUTPUT)

loop:
  // both forward
  drive(ENA, IN1, IN2, +1, 200); drive(ENB, IN3, IN4, +1, 200); wait 2 s
  // both backward
  drive(ENA, IN1, IN2, -1, 200); drive(ENB, IN3, IN4, -1, 200); wait 2 s
  // left forward, right backward
  drive(ENA, IN1, IN2, +1, 200); drive(ENB, IN3, IN4, -1, 200); wait 2 s
  // left backward, right forward
  drive(ENA, IN1, IN2, -1, 200); drive(ENB, IN3, IN4, +1, 200); wait 2 s
```
